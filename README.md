# في السوبر ماركت | At the Supermarket 🛒🇪🇬
> تطبيق تفاعلي لتعليم المحادثة بالعامية المصرية للبالغين ناطق بأصوات واقعية بتقنية Edge-TTS مع تمارين الفهم والاستيعاب.

---

## 🌟 مميزات التطبيق (Features)
- 🎙️ **محادثة صوتية واقعية**: حوار تفاعلي بين البائع والزبونة بنطق مصري قاهري طبيعي ومتقن (Microsoft Edge-TTS Neural Voices: Shakir & Salma).
- ⚡ **تحكم متقدم بالسرعة**: إمكانية الاستماع بالسرعة الطبيعية أو إبطاء الصوت (0.8x) لتسهيل الفهم والممارسة.
- 🏆 **تحدي الفهم والاستيعاب**: اختبار تفاعلي فوري لتقييم مدى فهم الحوار والمصطلحات والأسعار مع تعليقات توضيحية واحتفالات تشجيعية.
- 📱 **تصميم عصري متجاوب**: واجهة حديثة وسريعة تعمل بسلاسة على الموبايل والتابلت والكمبيوتر، متوافقة مع معايير الويب الحديثة.
- 🚀 **جاهز للنشر**: مهيأ تماماً للنشر على منصة Cloudflare Pages أو GitHub Pages.

---

## 📁 هيكل المشروع (Project Structure)
```text
├── index.html          # الهيكل الدلالي وعناصر الصفحة
├── style.css           # التصميم وتنسيقات الألوان والرسوم المتحركة
├── app.js              # محرك التشغيل والتحكم الصوتي واختبار الفهم
├── data.js             # بيانات الحوار ونصوص المحادثة وأسئلة الاختبار
├── generate_audio.py   # سكريبت بايثون لتوليد الصوتيات بالتشكيل المصري الدقيق
├── audio/              # ملفات الـ MP3 الصوتية لكافة أسطر المحادثة
├── wrangler.toml       # إعدادات النشر على Cloudflare Pages
└── _headers            # ترويسات الكاش والأمان
```

---

## 💻 التشغيل المحلي (Local Running)
يمكنك فتح ملف `index.html` مباشرة في أي متصفح حديث، أو تشغيل خادم محلي:

```bash
# باستخدام Python:
python -m http.server 8000

# أو باستخدام Node.js:
npx serve .
```
